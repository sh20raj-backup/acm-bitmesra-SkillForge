# ChatGPT-Style Generative UI

A detailed Agent Skill for building polished, accessible, responsive AI chat interfaces with typed, interactive components.

## Install

```bash
npx skills add acm-bitmesra/SkillForge --skill chatgpt-style-generative-ui
```

Then ask your compatible coding agent to read and follow the skill while auditing your current application.

## What it covers

- Repository-first audit and incremental implementation
- Chat shell, composer, streaming, history and message actions
- Typed response contracts and a fixed component registry
- Markdown, comparisons, metrics, charts, diagrams, timelines, forms, calculators, quizzes and citations
- Visual hierarchy, design tokens, responsive layouts, dark mode and motion
- Tool-driven UI and model integration
- Validation, security, privacy and accessibility
- Functional, responsive and security acceptance criteria
- A staged implementation plan and final-report expectations

## Important

The skill is an implementation guide, not a library or executable chat UI. A coding agent must implement the renderer, schemas, components and backend integration in the target application. It should preserve the existing architecture, verify current library APIs, and only claim tests it actually ran.

Read [SKILL.md](SKILL.md) for the complete instructions.
